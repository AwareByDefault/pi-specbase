## Outcome

`/spcb:kanban` displays the nearest or selected live Specbase store using authoritative stable identities, lifecycle columns, progress, stacks, diagnostics, and refresh behavior.

The Pi board and the Specbase headless snapshot show equivalent work-item state for the same store.

Action dispatch, workflow activity, and delivery automation remain deferred.

Consumes the public lifecycle and headless board APIs from the companion Specbase stack.
